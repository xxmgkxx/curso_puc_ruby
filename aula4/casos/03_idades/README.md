# Caso 3: média de idade a partir de um cadastro

## O prompt que a IA recebeu

> Os produtores preenchem a idade num formulário de texto. Escreva
> `media_de_idade(idades)` que recebe a lista de textos e devolve a média
> das idades.

A resposta está em `resposta_da_ia.rb`.

1. O que o `"não informado".to_i` devolve? Se não lembrar, teste no `irb`.
2. Qual média esse método devolve?
3. Qual média está **certa**, na sua opinião? Atenção: esta é a parte difícil.
   Qual é a decisão certa quando um dado não existe?
